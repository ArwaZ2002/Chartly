=============================================================
PROJECT REPORTS FEATURE - IMPLEMENTATION PLAN
Chartly MVP
=============================================================

SUMMARY
-------
Add a "Reports" feature: users select existing charts, get per-chart
AI analysis via Grok, assemble into a full markdown report, edit
manually, improve with AI, and export as PDF with embedded chart
images. Uses a fixed, professional default PDF layout; custom report templates can be added as a future feature.

AI Provider: Grok (xAI API, OpenAI-compatible at api.x.ai)
Markdown Editor: marked.js from CDN
PDF Charts: kaleido for Plotly chart -> PNG rendering

5. AI SERVICE (backend/app/services/ai_service.py)
=============================================================

Uses openai SDK with base_url="https://api.x.ai/v1".

FUNCTION 1: analyze_single_chart(chart_title, chart_type, data_summary) -> str

  Uses this exact prompt:

  "You are a professional data analyst. Analyze the following chart
  based only on the provided data.

  Chart title: {chart_title}
  Chart type: {chart_type}
  Data summary: {data_summary}

  Provide:
  1. Key observation
  2. Important trend
  3. Anomaly or notable pattern
  4. Business interpretation

  Keep the explanation concise and factual. Do not invent information
  that is not supported by the data."

  data_summary construction:
    - Chart spec: dimension, metric, aggregation, chart_type, title
    - Dataset profile: column names, types, row_count
    - Pandas stats: df[dimension].value_counts().head(10),
                    df[metric].describe() for numeric


FUNCTION 2: generate_full_report(title, chart_analyses, instructions?) -> str

  Prompt:
  "You are a professional data analyst writing a project report.
  Below are analyses of individual charts from the project. Combine
  them into a cohesive, well-structured report in markdown format.

  Report title: {title}
  {optional instructions}

  Chart analyses:
  {each analysis with chart title as subheading}

  Write:
  1. Executive summary (2-3 sentences)
  2. For each chart: include the analysis with a section heading
  3. Overall trends and patterns across all charts
  4. Key recommendations

  Use markdown formatting with proper headings, bullet points,
  and emphasis."


FUNCTION 3: improve_report_content(existing_content, instructions?) -> str

  Prompt:
  "Improve the following report content. Make it more professional,
  fix grammar, improve clarity, and ensure data-driven language.

  {instructions if provided}

  Current content:
  {existing_content}"

6. PDF GENERATOR (backend/app/services/report_pdf_generator.py)
=============================================================

Uses fpdf2, markdown, plotly.io.to_image() (kaleido backend).

FUNCTION: generate_report_pdf(report, charts_data) -> bytes

  Flow:
  1. Parse markdown content -> HTML via
     markdown.markdown(content, extensions=['tables', 'fenced_code'])
  2. For each chart in chart_ids:
     - Load chart spec + dataset
     - Generate Plotly JSON via generate_chart(df, spec)
     - Convert to PNG via pio.to_image(fig, format="png",
       width=1200, height=600, scale=2)
  3. Build PDF with fpdf2 using a fixed, professional default report layout:
     - Cover page: title, author name, date, accent line
     - Content: pdf.write_html(html_content) for markdown HTML
     - Chart images: pdf.image(png_bytes) directly after their relevant analysis section
     - Consistent headers/footers, margins, typography, spacing, and page numbering
  4. Return PDF as bytes

7. API ROUTES
=============================================================

--- backend/app/api/reports.py ---

  POST   /api/reports/                 Create report           (analyst+)
  GET    /api/reports/                 List all reports        (any)
  GET    /api/reports/{id}             Get report              (any)
  PUT    /api/reports/{id}             Update report           (analyst+)
  DELETE /api/reports/{id}             Delete report           (analyst+ or author)
  POST   /api/reports/{id}/export      Download PDF            (any)
  POST   /api/reports/ai/analyze-chart Per-chart analysis      (analyst+)
  POST   /api/reports/ai/generate      Full report from analyses (analyst+)
  POST   /api/reports/ai/improve       Improve content         (analyst+)

  /ai/analyze-chart:
    Accepts { chart_id }
    Loads chart + dataset, builds data_summary
    Calls analyze_single_chart()
    Returns { chart_id, analysis }

  /ai/generate:
    Accepts { title, chart_ids, instructions? }
    Loops through chart_ids calling analyze_single_chart() for each
    Then calls generate_full_report() with all analyses
    Returns { title, content (markdown), analyses: [{chart_id, analysis}] }

  /ai/improve:
    Accepts { content, instructions? }
    Calls improve_report_content()
    Returns { content }

  /export:
    Loads report, renders all charts
    Calls generate_report_pdf()
    Returns Response(pdf_bytes, media_type="application/pdf",
      headers={"Content-Disposition": f'attachment; filename="{report.title}.pdf"'})
